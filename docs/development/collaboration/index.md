# Collaboration

This open-source software is a collaborative effort. <br>
The repository has several elements to provide necessary functions.

To participate in the development you can do the following:

- Contribute to the [GitHub Discussions](https://github.com/OpenEnergyPlatform/oemetadata/discussions)
- Contribute to the [GitHub Issues](https://github.com/OpenEnergyPlatform/oemetadata/issues)
- Follow the [workflow for collaborative development](https://github.com/OpenEnergyPlatform/oemetadata/blob/production/CONTRIBUTING.md)
- Get in touch with the community on the [Element Chat](https://openenergyplatform.github.io/oemetadata/latest/development/collaboration/chat/)
- Meet the developers in one of the [regular meetings](https://openenergyplatform.github.io/oemetadata/latest/development/collaboration/meeting/)
